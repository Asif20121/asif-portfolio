ASIF MOSTOFA MD. NISHAT — PORTFOLIO WEBSITE

Files:
- index.html: complete responsive portfolio website.

How to use:
1. Extract the ZIP file.
2. Open index.html in a web browser to preview it.
3. To publish it, upload index.html to your web hosting public_html folder,
   or deploy the folder using GitHub Pages, Netlify, or Vercel.

Before publishing:
- Add live demo / GitHub repository links for individual projects.
- Review the project descriptions and update any details that need more precision.
- Add a downloadable CV link if you want visitors to download your resume.
- Confirm the phone number and email address are current.

This is a static website and does not require a backend or database.
